## Hi 👋

I'm **Júlio Carneiro** — Senior Frontend Engineer building for the web **since 2009**: web and mobile products for SaaS, FinTech, Health, Web3, e-commerce and media.

I specialize in **Frontend Architecture**, **Web Performance**, **Security** and **Developer Experience** — working with React, Next.js, TypeScript and React Native. I also have a background in Graphic Design, 3D modeling and video editing, so I work closely with UX/UI teams to ship interfaces that are visually precise, fast and accessible.

- 🔭 Currently at **VoA Health**, leading the frontend architecture: Next.js, real-time collaboration (Liveblocks + Tiptap) and mobile apps in **React Native, Flutter and Capacitor**
- 🎯 **100/100 on Google PageSpeed** for Mitsubishi Motors Brazil and VoA's key pages
- 🧪 **100% unit test coverage** at Munchies (Jest + React Testing Library)
- 🚀 Built and run two SaaS products of my own: **[MotoDeck](https://www.motodeck.com.br)** and **[UnderPass](https://www.underpass.com.br)**
- 📦 Libraries published on **npm**: ChordKit (6 packages) and TabKit (5 packages)
- 🔐 Certified in **Cybersecurity & Ethical Hacking** (Cisco, IBSEC, CSIRT) — author of **FrontGuard**, an open source frontend security scanner
- 🎨 Studying **Graphic Design** (Anhembi Morumbi) — 3D, packshots and video at [juliocarneiro.art](https://juliocarneiro.art)
- ✍️ 10 articles on React, React Native and web security for **Tableless**, **React Brasil** and my [blog](https://medium.com/@juliocarneiro)
- 💬 Ask me about: React architecture, micro frontends, web performance, frontend security or music production
- ⚡ Currently exploring: advanced TypeScript patterns, accessibility engineering
